# NihonGo! Frontend

React + Vite frontend for NihonGo!, a Japanese learning platform for English speakers.

## Features

- Authentication screens
- Dashboard
- JLPT modules
- Lesson details and exercises
- Kana/Kanji trainer
- Flashcard decks and review flow
- Light/dark theme

## Tech Stack

- React
- Vite
- React Router
- TanStack Query
- Axios
- Tailwind CSS
- Oxlint
